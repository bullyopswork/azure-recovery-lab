# Recovery Lab visual system

Audience: an engineer evaluating service behavior and portfolio evidence.
Direction: quiet operational notebook. Warm paper, charcoal text, green healthy state, red failure, blue links. No invented telemetry or decorative charts.

CSS role tokens live in recovery_lab/static/style.css. Type is system sans, with monospace identities and event observations. Spacing:8/16/24/32/48px. Radius:4px. Surfaces use borders, not shadows. Controls use explicit hover/active/focus states; there are no disabled mutation buttons because the public dashboard is read-only. Connecting, healthy, failing and unreachable states are distinct in words, not just color. Mobile uses a single column. Browser observations are explicitly not durable cloud evidence.
